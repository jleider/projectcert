# projectcert

A catalog of every U.S. state education agency's teacher certification
requirements for instructing classified English Learner (EL) students,
with a web UI for browsing the data state-by-state.

## Scope

- **Subject**: Teacher certification requirements for EL instruction.
- **Coverage**: All 50 U.S. states + D.C., sourced from each state's
  education agency.
- **Form**: Structured catalog data + web app to browse it.
