# AR — DESE Educator Licensure Area list

**URL:** https://dese.ade.arkansas.gov/Offices/educator-effectiveness/educator-licensure-area
**Snapshot:** `educator-licensure-area.html`
**Retrieved:** 2026-05-08 by projectcert-2026

## Key findings

Public-facing list of all Arkansas licensure areas and codes.

- **English as a Second Language (ESL)** — code **247**, K-12, "Special Subjects" category, type: **Endorsement**.
- **English for Speakers of Other Languages (ESOL) — Ancillary** — code 100, K-12, type: Ancillary (the same area on an Ancillary License pathway).
- No bilingual-education endorsement. Foreign-language endorsements
  (Spanish 710, French 248, German 702, etc.) exist but are world-
  language teaching credentials, not bilingual-program credentials.

## Implication

- `bilingual.offered = false` (unchanged from baseline).
- `eld.offered = true; eld.addOn = true; eld.standalone = false`
  (unchanged from baseline).
