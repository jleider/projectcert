# English Learner and Bilingual Authorizations (CTC Employer Manual)

URL: https://www.ctc.ca.gov/employers/manuals/english-learner-and-bilingual-authorizations/
Retrieved: 2026-05-08 via WebFetch.
Issuer: California Commission on Teacher Credentialing (CTC).

## Key confirmations

- Embedded EL preparation since 7/1/2002 (AB 1059): "All teacher
  candidates admitted to a California Multiple or Single Subject
  Teacher Credential Program on or after July 1, 2002 complete embedded
  English learner coursework authorized under Assembly Bill 1059."
- BCLAD is retired; current new-issue path for bilingual instruction is
  the add-on Bilingual Authorization (per AB 1871, 2008).
- The legacy Bilingual Crosscultural Specialist Credential is referenced
  for historical recognition only; not issued as a primary new-issue
  pathway.

## Coding implication

Confirms `credentials.eld` standalone via embedded preparation in
initial credentials, and `credentials.bilingual` add-on as the current
new-issue pathway.
