# OSSE — English Learner Policy and Programs

Source URL:
https://osse.dc.gov/page/english-learner-policy-and-programs

Retrieved: 2026-05-07

## Key facts

- DC's annual ELP assessment is **ACCESS for ELLs** (WIDA
  Consortium).
- OSSE references the WIDA English Language Development Standards,
  2020 edition; uses the WIDA Screener K-12 for EL identification.
- Five program models are available to LEAs: dual language,
  inclusion/collaborative teaching, content-based ESL, sheltered
  content, newcomer. **Sheltered English instruction is not
  mandated** for all teachers — schools select based on student
  needs.
