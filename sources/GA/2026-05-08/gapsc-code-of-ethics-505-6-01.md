# GaPSC Rule 505-6-.01 — The Code of Ethics for Educators

Source: https://www.gapsc.com/Rules/Current/Ethics/505-6-.01.pdf
Effective: January 1, 2024
Retrieved: 2026-05-08
File: gapsc-code-of-ethics-505-6-01.pdf

## Summary

The Code of Ethics for Educators governs professional conduct for Georgia
educators (Standards 1–10): legal compliance, conduct with students,
alcohol/drugs, honesty, public funds, remunerative conduct,
confidentiality, abandonment of contract, certificate misuse,
testing, reporting.
