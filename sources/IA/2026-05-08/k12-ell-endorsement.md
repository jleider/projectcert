# K-12 English Language Learners (Endorsement 104) — Iowa DOE

- URL: <https://educate.iowa.gov/educator-licensure/endorsements/k-12-english-language-learners>
- Snapshot: `k12-ell-endorsement.html`
- Retrieved: 2026-05-08

Endorsement 104, K-12 English Language Learners. The page lists 18
Iowa colleges and universities with approved ELL endorsement programs
(approved-program path is real). Worksheet is at
`/media/115/download?inline`. Page itself does not enumerate hour-by-
hour requirements — those are codified in IAC 282-13.28(20).

Per the endorsements-overview page, additional endorsements are added
"by submitting an application and meeting the current requirements in
Iowa Administrative Code 282-13.26-28," with two pathways:

1. Recommendation route — approval from an Iowa-approved teacher-prep
   institution (the "approved program" path).
2. State Minimums route — transcripts reviewed by the BoEE, requiring
   a C- or higher in each course (the "transcript review" path).

This confirms `eld.requirements.program: true` (approved program is a
real Iowa pathway) and `eld.requirements.coursework: true` (transcript
review against state minimums is the alternative path).

Practicum, content test, and language proficiency: none specified at
the endorsement level — see `iac-282-13-28.md` for rule text. Mark
those as `null` (ambiguous; no rule-level mandate but providers may
include practicum at their discretion).
