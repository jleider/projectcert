## Transition

Illinois adopted a new set of Professional Educator Standards
(23 IAC 24.140) that take effect **July 1, 2026**. The 2013 Illinois
Professional Teaching Standards (24.130) remain operative through
June 30, 2026.

Refresh date is 2026-05-08, so 24.130 is the current operative
document. Per project convention, code against the operative
document on refresh date.

## Mentions in 24.140 (new standards, effective 2026-07-01)

### diverse
- A4 (Instructional Assessment): "Reflecting the spectrum of
  diversity individually and for groups of learners in assessment
  choices."

### cultural / culturally
- LE3: "Integrating culturally responsive materials and resources..."
- IN8: "Integrating curricular content based on individual learners'
  and families' cultural assets."
- IN14: "Integrating culturally responsive instructional strategies."
- CC2: "Collaborating with families and professionals in culturally
  sustaining ways."
- CC6: "Effectively communicating in culturally sustaining ways..."

### linguistic / language
- IN18: "Engaging learners in using academic language."
- A6: "...progress across the developmental spectrum (physical,
  cognitive, social, emotional, linguistic, etc.)."

### English Learner / ELL / English language learner
- **No explicit "ELL," "EL," or "English learner" reference.**
