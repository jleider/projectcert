# NCES Digest Table 204.20 — Kentucky EL percent

- Retrieved: 2026-05-08
- URL: https://nces.ed.gov/programs/digest/d23/tables/dt23_204.20.asp
- File: nces-table-204.20.html

## Finding

Kentucky, fall 2021 (most recent in this Digest table):
- Number of ELs: **35,434**
- Percentage of total public K-12 enrollment: **5.4%**

Fall 2011 comparison: 18,579 ELs (2.7%). Roughly doubled over a decade.

## Coding decision

- elPercent: **5.4** (was 0.9)
- elPercentAsOf: **2021-10-01** (was 2019-10-01)

The baseline-2019 value (0.9%) is implausibly low and inconsistent with
NCES historical data for KY — the 2011 figure was already 2.7%. The
0.9% likely reflects a coding error or an alternate metric used in the
seed paper, not an actual SEA-reported share. We replace it with NCES
Table 204.20 fall 2021 for cross-state comparability per the project's
elPercent sourcing rule (NCES preferred over per-SEA numbers).
