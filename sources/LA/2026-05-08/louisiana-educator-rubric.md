## Implication for schema

This is a substantive change vs. baseline-2019, which coded LA's
prior teacher standards as `diverse: true, cultural: false,
linguistic: false, el: true`. The new April 2024 LEADS Educator
Rubric — the one Louisiana educators are now actually evaluated
against — does not name diverse learners, cultural responsiveness,
linguistic diversity, or ELs in any indicator.

- professionalStandardsMentions.diverse = false
- professionalStandardsMentions.cultural = false (the "cultural
  centers" mention is incidental)
- professionalStandardsMentions.linguistic = false
- professionalStandardsMentions.el = false

This is a meaningful policy regression from the perspective of EL
teacher quality: Louisiana's former rubric (Compass) cited EL
support as part of effective practice; the replacement rubric
does not.

Louisiana's professional teaching standards in the older sense —
Educator Code of Ethics, the InTASC-aligned content standards
embedded in EPP review — do still reference diverse learners. But
the rubric used in the field for educator evaluation, which is what
the schema field is designed to capture, does not.
