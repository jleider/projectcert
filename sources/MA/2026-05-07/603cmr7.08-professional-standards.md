# 603 CMR 7.08 — Professional Standards for Teachers

Source: https://www.doe.mass.edu/lawsregs/603cmr7.html?section=all
Retrieved: 2026-05-07

This is the Massachusetts professional teaching standards document
for the purpose of `professionalStandardsMentions` in our schema.
(603 CMR 35.00 is the Educator Evaluation rubric — separate document
which only has explicit mentions of "diverse" and "cultural" via the
Cultural Proficiency indicator. We use 7.08 because it is the SEA's
named *professional standards for teachers*.)

## Four standards

1. Curriculum, Planning, and Assessment
2. Teaching All Students
3. Family and Community Engagement
4. Professional Culture

## Indicators referencing EL / cultural / linguistic / diverse

- "Uses approaches supporting students of **diverse cultural and
  linguistic** backgrounds."
- "Uses strategies for making content accessible to **English
  learners**."
- "Demonstrates knowledge for planning instruction for **English
  learners** at various levels of English language proficiency."
- "Creates an environment that values **diversity**."
- "Collaborates with families, recognizing **native language and
  culture**."

## Mapping to schema fields

- diverse: TRUE
- cultural: TRUE
- linguistic: TRUE
- el: TRUE
