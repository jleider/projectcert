# Maine DOE — English Language Proficiency Assessments (MECAS / ACCESS)

- Source: https://www.maine.gov/doe/Testing_Accountability/MECAS/materials/access
- Snapshot: `doe-mecas-access.html`
- Retrieved: 2026-05-08

Confirms Maine's ELP assessment:

- **Test name:** ACCESS for ELLs (WIDA ACCESS Online for grades 1–12; WIDA ACCESS for Kindergarten; WIDA Alternate ACCESS for students with significant cognitive disabilities, K–12).
- **Consortium:** WIDA. Maine adopted the WIDA ELD Standards 2020 Edition in spring 2021.
- **Statutory basis:** ESSA-required annual assessment for MLs.
