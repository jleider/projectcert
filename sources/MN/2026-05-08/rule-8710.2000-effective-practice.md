## professionalStandardsMentions coding

Searching the current text for the four schema flags:

- **diverse**: TRUE.
  - Std 2.A: "diversity of student cultures"
  - Std 4.F: "diverse perspectives on race, culture, language, gender,
    sexual identity, ability, religion, nationality"
  - Std 5.E: "diverse cultural ways of knowing"

- **cultural**: TRUE.
  - Std 1.A: language, culture, family, and community values
  - Std 1.D: "cultural background … to make meaningful connections"
  - Std 4.E: "anti-racist, culturally relevant, and responsive
    instructional strategies"

- **linguistic**: TRUE.
  - Std 1.H: "the role of language and culture in learning … modify
    instruction to make language comprehensible"
  - Std 1.I: "language development and the benefits of multilingualism
    and multiliteracy"
  - Std 4.A: "Minnesota's English Language Development Standards
    Framework"

- **el**: TRUE.
  - Std 4.A explicitly references "Minnesota's English Language
    Development Standards Framework," i.e. the EL-facing standards
    framework. The rule's references to "second language," "L1/L2
    acquisition," and "comprehensible" language instruction also speak
    directly to EL pedagogy. While the literal phrase "English
    learner" is absent in the version we read, the EL-specific
    framework is named explicitly.

  Coding `el: true` is consistent with the baseline. If a future
  refresh shows the ELD Standards Framework reference removed, this
  flag should be revisited.

## Notes

8710.2000 was substantially revised under the 2022 PELSB rulemaking
(Tier-licensure framework + Standards of Effective Practice update).
Current text reads stronger on diversity/equity and explicitly names
the MN ELD Standards Framework — language not in the 2014-era
baseline. No flag changes from baseline (all four already true), but
the textual basis is now stronger.
