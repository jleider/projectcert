# OPI English Learners page

- URL: https://opi.mt.gov/Families-Students/Family-Student-Support/English-Learners
- Retrieved: 2026-05-08

## Key facts extracted

- **ELP assessment**: WIDA ACCESS for ELLs.
- **WIDA standards**: Montana uses the WIDA English Language
  Development Standards (2020 Edition K-12). Framework PDF link
  provided on the page.
- **Terminology**: page uses "English Learners (ELs) and Multilingual
  Learners (MLs)" — both terms in current SEA usage; we keep the
  canonical term `EL` per project terminology guide.
- **EL Specialist contact**: Serena Wright, serena.wright@mt.gov.
- **Seal of Biliteracy**: links out to the Board of Public Education
  page (bpe.mt.gov) and the FAQ PDF on opi.mt.gov.
- **No ESL-specific teacher credential mandate is stated** on this
  page. The page does not require classroom teachers to hold the ESL
  endorsement; it points to TeachMontana for credential lookups.
