# ESPB — Types of Licenses page

Source URL: https://www.nd.gov/espb/licensure/license-information/types-licenses
Retrieved: 2026-05-08

ESPB's master list of license and endorsement types currently issued.

## Endorsements (added to a base teaching license)

- **English Learner (EL) Endorsement** (a.k.a. NDAC 24000 ELD)
- Kindergarten Endorsement
- Out-of-Field Endorsement
- Major Equivalency Praxis Endorsement
- (Bilingual education endorsement, NDAC code 24500, exists in
  administrative code but is not surfaced as a separate item on
  this page — it is treated as an extension of the EL endorsement.)

## Standalone licenses

Initial In-State, Two-Year Renewal, Five-Year Renewal, Interim
Substitute, Alternate Access, Initial Alternate Pathway American
Board, Out-of-State Reciprocal, OSEL, Re-Entry, Probationary, 40-Day
Provisional, 25-Year Life, Native American Language/Culture License,
School Counselor, School Psychologist (Intern), School Psychologist,
Speech Language Pathology.

## Coding implications

- ND has no SEI mandate for all teachers — there is no general SEI
  course/exam requirement attached to the base teaching license.
  credentials.sei.mandatedForAllTeachers stays false.
