# NDDPI — ACCESS for ELLs

Source URL: https://www.nd.gov/dpi/districtsschools/assessment/access-ells
Retrieved: 2026-05-08

Authoritative confirmation that North Dakota uses WIDA ACCESS for
ELLs.

## Verbatim

> "WIDA ACCESS for ELLs is the annual North Dakota English Language
> Proficiency Assessment in which all English Learners must
> participate."

The assessment covers four domains (listening, speaking, reading,
writing) and is aligned to ND's adopted WIDA English Language
Development Standards. All ELs in grades K–12 participate annually.
