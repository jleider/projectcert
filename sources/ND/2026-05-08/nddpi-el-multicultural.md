# NDDPI — English Learner / Multicultural Education

Source URL: https://www.nd.gov/dpi/education-programs/english-learnermulticultural-education
Retrieved: 2026-05-08

NDDPI's program-level home for EL/multicultural education in ND
public schools. Confirms ND uses the WIDA ELD Standards Framework
(2020 Edition) and operates an English Language Program Advisory
Committee (ELPAC).

The page also surfaces sub-pages for:

- EL Guidance and Resources
- EL Data and Reporting (STARS — MIS01 Fall Report, MIS02/MIS03
  staffing)
- ND Seal of Biliteracy
- ACCESS for ELLs

## Coding implications

- elpAssessment: ACCESS for ELLs (WIDA) confirmed as ND's annual ELP
  assessment via the linked ACCESS for ELLs page (see
  nddpi-access-ells.md).
- sealOfBiliteracy: program is operated by NDDPI; landing page exists
  under the EL/Multicultural section.
- This is NDDPI (the SEA's program/policy arm). Educator licensure
  itself is administered by ESPB, an independent body.
