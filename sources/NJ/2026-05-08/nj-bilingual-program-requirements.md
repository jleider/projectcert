# NJ Bilingual Education Program Requirements (district-side)

Source: https://www.nj.gov/education/title3/district/program_blerequirements.shtml
Retrieved: 2026-05-08
Retrieved by: projectcert-2026

## Key facts

- LEA must implement a bilingual education program when there are 20 or
  more students in a single language group.
- Districts may run full-time bilingual education or dual-language
  immersion (DLI) models.
- Teacher requirements:
  - For NJSLS content delivery: instructional certificate + Bilingual/
    Bicultural endorsement.
  - For ELD: ESL endorsement.
- DLI: instructional certificate with Bilingual/Bicultural endorsement
  *or* with World Language certificate, plus demonstrated linguistic
  competence in program language and ESL endorsement for ELD.
- 2023 amendments shifted emphasis from transitional bilingual programs
  toward biliteracy as an end goal.
