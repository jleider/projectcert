# NJDOE — Multilingual Learners (MLs) Educator Certification overview

Source: https://www.nj.gov/education/title3/educators/certification.shtml
Retrieved: 2026-05-08
Retrieved by: projectcert-2026

## Summary

NJDOE's Office of Recruitment, Preparation, and Certification supports
candidates pursuing two MLL-related instructional endorsements:

1. **Bilingual/Bicultural Education** (endorsement code 1480)
2. **English as a Second Language** (endorsement code 1475)

Candidates "complete the requirements at a state approved ESL or
bilingual program." NJDOE lists 13 universities with approved
Bilingual/Bicultural programs and 14 with approved ESL programs.

## Schema implications

- Confirms add-on endorsement model for both credentials.
- Confirms `requirements.program: true` (state-approved program path)
  for both bilingual and ELD.
- "Test only" is **not** a clean alternative pathway in NJ — both paths
  ultimately require either an approved program or substantial
  coursework plus the language-proficiency test. Treat the program path
  as primary.
