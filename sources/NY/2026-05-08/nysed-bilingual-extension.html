Extension (Bilingual)

This type of certificate is currently available for applicants and is within the Annotation and Extension area of interest.

Extension (Bilingual)

Description

An extension of this type is attached to a valid base certificate, authorizing the holder to teach bilingual education. The individual must hold the appropriate base certificate.

Validity

Valid as long as the base certificate remains valid.

Application Fee

$50 based on completion of a New York State approved program
$100 using all other pathways.

Paper Certificate Printed?

No this certificate is NOT printed at the time of issuance.
Verify this certification in the TEACH System.
Holders of this type of extension may apply for a printed certificate.
