# RIDE — Multilingual Learners (MLLs) / English Learners (ELs)

URL: https://ride.ri.gov/students-families/multilingual-learners-mlls-english-learners-els
Retrieved: 2026-05-08

The SEA's central student-services landing page for MLL/EL policy.
Establishes (a) which ELP assessment RI uses and (b) which
EL-instructional program models LEAs may select.

## ELP assessment

> "Rhode Island uses ACCESS for ELLs 2.0 through WIDA. The state
> requires annual measurement of English language proficiency for all
> English language learners. The WIDA SCREENER is used to screen
> newly enrolling students identified as potential MLLs/ELLs."

Confirms the existing record:
- elpAssessment.name = "ACCESS for ELLs"
- elpAssessment.consortium = "WIDA"

## Program models LEAs may choose

Bilingual Education:
- One-Way Dual Language
- Two-Way Dual Language
- Transitional Bilingual Education
- Transitional Bilingual Education for Students with
  Limited/Interrupted Formal Education

Content-Based Education:
- Content-Based Instruction
- Content-Based Instruction for Newcomers
- Content-Based Instruction for Students with Limited/Interrupted
  Formal Education

Notably, "sheltered English instruction" is not a separate listed
model — RI uses content-based instruction terminology — and the
state does not mandate it for all teachers.

## SEI mandate

No statewide mandate that all teachers complete SEI training. RI has
no SEI mandate analogous to AZ/CA/MA.
